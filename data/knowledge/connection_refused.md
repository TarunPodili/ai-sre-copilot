# Connection Refused

An application cannot establish a connection to another service.

Common Causes:
- Target service unavailable
- Incorrect port
- Service not listening
- Network policy
- Incorrect endpoint

Evidence:
- Connection refused
- ECONNREFUSED
- Failed to connect

Diagnostics:
- Check service status
- Verify host and port
- Check network policies

Remediation:
Restore target service or correct connection configuration.
