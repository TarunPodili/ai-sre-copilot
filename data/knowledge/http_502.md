# HTTP 502 Bad Gateway

A gateway or reverse proxy received an invalid response from an upstream service.

Common Causes:
- Upstream service unavailable
- Application crash
- Incorrect proxy configuration
- Network connectivity issue

Evidence:
- HTTP 502
- Bad Gateway
- upstream connection failure

Diagnostics:
- Check upstream service
- Check application logs
- Check proxy configuration

Remediation:
Restore upstream service or correct proxy configuration.
