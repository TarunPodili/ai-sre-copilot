# Permission Denied

An application or deployment lacks permission to access a resource.

Common Causes:
- Incorrect IAM/RBAC permissions
- File permissions
- Invalid credentials
- Missing service account permissions

Evidence:
- Permission denied
- Access denied
- Forbidden
- HTTP 403

Diagnostics:
- Check identity
- Check IAM/RBAC policies
- Verify service account

Remediation:
Grant the minimum required permission.
