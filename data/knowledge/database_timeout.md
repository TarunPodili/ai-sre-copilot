# Database Connection Timeout

Database connection attempts exceed the configured timeout.

Common Causes:
- Database unavailable
- Network issue
- Incorrect endpoint
- Connection pool exhaustion
- Firewall restriction

Evidence:
- connection timeout
- database timeout
- timeout connecting to database

Diagnostics:
- Verify database availability
- Check endpoint
- Check network connectivity
- Check connection pool

Remediation:
Verify database endpoint and connectivity.

Prevention:
Database health monitoring and connection alerts.
